# Security Policy / Sicherheitshinweise

**Report a vulnerability / Schwachstelle melden:** GitHub → Security → "Report a vulnerability"
(private vulnerability reporting). Please do not open public issues for vulnerabilities.

## Scope and honest limits / Grenzen
Claudios is open source. The abuse protections (limits, HTTPS-only, verification levels) prevent
accidental or convenient misuse; they cannot stop someone who forks and modifies the code.
Use only on systems you own or are authorised to test (cf. § 202c StGB / local law). No warranty.
